Explanation:
In Python's `pathlib` library, **`parents=True`** tells the `.mkdir()` method to automatically create any missing parent (intermediate) directories in the path if they don't already exist.

It is the Python equivalent of the Unix command `mkdir -p`.

---

### Why do you need it?

Imagine your `root` folder is `project`, and your `folder` variable is `data/processed/csv`.

* **Without `parents=True**`: If the `project/data/processed` folder doesn't already exist, Python will throw a **`FileNotFoundError`** because it refuses to create a folder inside a directory that isn't there yet.
* **With `parents=True**`: Python checks the path, sees that `data` and `processed` are missing, creates them first, and then creates `csv` inside them—all in one smooth step.
---
### What about `exist_ok=True`?

Right next to it, you have `exist_ok=True`. This tells Python:

> *"If the folder already exists, don't crash or throw an error—just ignore it and move on."*

Together, **`parents=True, exist_ok=True`** is a very common safety pattern in Python scripts because it guarantees that your code will successfully create the directory structure whether it's brand new or already exists, without ever crashing due to missing folders or duplicate creation attempts.
